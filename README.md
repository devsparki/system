IDEIA DO SISTEMA
O projeto consiste no desenvolvimento de um sistema para facilitar o agendamento e o gerenciamento de aulas de artes marciais, como Muay Thai, Jiu-Jitsu e Boxe.
O sistema será organizado por cidade e modalidade, permitindo que alunos encontrem o centro de treinamento desejado e tenham acesso às informações das aulas disponíveis. O usuário poderá realizar um cadastro, escolher a modalidade, informar se é criança ou adulto e visualizar os dias e horários disponíveis para realizar o agendamento.
A plataforma também terá como objetivo facilitar o trabalho dos professores e responsáveis pelo centro de treinamento. Por meio do sistema, será possível organizar os horários das aulas, visualizar os alunos matriculados e acompanhar os agendamentos, evitando conflitos de horários e facilitando o controle das turmas.
Dessa forma, o sistema busca tornar o processo de agendamento mais rápido, organizado e acessível, tanto para os alunos quanto para os professores.
FUNCIONALIDADES PRINCIPAIS
• Cadastro e login de usuários;
• Cadastro de professores e alunos;
• Seleção da cidade e centro de treinamento;
• Escolha da modalidade: Muay Thai, Jiu-Jitsu ou Boxe;
• Separação das aulas para crianças e adultos;
• Visualização dos dias e horários disponíveis;
• Agendamento e cancelamento de aulas;
• Visualização dos agendamentos realizados;
• Área para o professor gerenciar suas aulas e horários;
• Controle de alunos inscritos em cada turma;
• Organização dos horários para evitar conflitos.
TECNOLOGIAS UTILIZADAS
• HTML – estrutura das páginas;
• CSS – estilização e layout;
• JavaScript – interações e funcionalidades do sistema;
• SQL – criação e gerenciamento do banco de dados;
• Figma – criação do protótipo e design das telas.
DESENVOLVIMENTO
Primeiramente, será utilizado o Figma para desenvolver o protótipo das telas e definir a estrutura visual do sistema. Depois, o protótipo será transformado em uma aplicação web utilizando HTML, CSS e JavaScript no frontend.
No backend, será utilizado JavaScript para desenvolver a lógica do sistema e SQL para armazenar e gerenciar informações como usuários, professores, modalidades, horários e agendamentos.
O objetivo final é criar um sistema funcional que facilite o agendamento de aulas e o gerenciamento do centro de treinamento, proporcionando uma experiência simples para os alunos e uma organização maior para os professores.
