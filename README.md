## 📌 Sobre o Projeto

O **Sistema GFG (Centro de Treinamento)** é uma plataforma web desenvolvida para facilitar o agendamento e o gerenciamento de aulas de artes marciais.

O sistema permitirá que alunos encontrem centros de treinamento por cidade e modalidade, consultem os horários disponíveis e realizem agendamentos de forma simples e organizada.

Além disso, a plataforma oferecerá ferramentas para professores e responsáveis pelos centros de treinamento gerenciarem aulas, horários, turmas e alunos matriculados.

### 🎯 Objetivo

Tornar o processo de agendamento de aulas mais **rápido, acessível e organizado**, melhorando a experiência dos alunos e facilitando o gerenciamento dos centros de treinamento.

---

## 🥋 Modalidades Disponíveis

O sistema será desenvolvido para atender diferentes modalidades de artes marciais:

| Modalidade | Descrição |
|---|---|
| 🥊 Muay Thai | Treinamento de técnicas de combate e condicionamento físico. |
| 🥋 Jiu-Jitsu | Prática de técnicas de luta e defesa pessoal. |
| 🥊 Boxe | Treinamento de golpes, movimentação e resistência física. |

As aulas serão organizadas de acordo com a faixa etária:

- 👶 Crianças
- 🧑 Adultos

## 🚀 Desenvolvimento

O desenvolvimento do Sistema GFG será dividido em etapas:

### 1️⃣ Prototipação

Inicialmente, será utilizado o **Figma** para criar o protótipo das telas e definir a estrutura visual da plataforma.

Nessa etapa, serão planejados os principais fluxos de navegação, como cadastro, seleção de modalidades e agendamento de aulas.

### 2️⃣ Desenvolvimento do Frontend

O protótipo será transformado em uma aplicação web utilizando:

- HTML para estruturação.
- CSS para estilização.
- JavaScript para interações e funcionalidades.

O objetivo é criar uma interface simples, intuitiva e responsiva.

### 3️⃣ Desenvolvimento do Backend

O backend será desenvolvido utilizando JavaScript para implementar a lógica do sistema, incluindo:

- Gerenciamento de usuários.
- Controle de professores e alunos.
- Organização das aulas e horários.
- Processamento dos agendamentos.

### 4️⃣ Banco de Dados

O SQL será utilizado para armazenar e gerenciar informações importantes, como:

- Usuários.
- Professores.
- Alunos.
- Centros de treinamento.
- Cidades.
- Modalidades.
- Turmas.
- Horários.
- Agendamentos.

### 5️⃣ Integração e Testes

Na etapa final, frontend, backend e banco de dados serão integrados para formar um sistema funcional.

Serão realizados testes para verificar o funcionamento dos agendamentos, o gerenciamento das turmas e a prevenção de conflitos de horários.
